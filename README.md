# Hisscore

Flutter retro Snake game. The app lives in [`Hisscore/`](Hisscore/README.md).

Six modes, a daily challenge with a different rule every week and a ghost
of your best run to race, friend challenge codes, quests, XP, milestones,
unlockable looks, and global leaderboards. Android; iOS has never been
built.
